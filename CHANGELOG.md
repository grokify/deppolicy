## [v0.1.0] - 2026-08-29 ([`1a55648`](https://github.com/grokify/deppolicy/commit/1a55648))

### Highlights

- Default-deny dependency policy engine: an authored policy.json declares which components may directly depend on which others, a scanner produces a graph.json of what actually exists, and a pure evaluator reports where reality diverges from intent — with a ratchet mode so enforcement starts before historical coupling is fully classified
- Ecosystem-neutral component model: Go modules, directories within them (proto-modules), npm packages, crates, container images, and services are all locatable components; Go ships as the first and reference scanner
- Tier system with explicit, non-transitive allow-lists plus deny patterns that can reach third-party targets (e.g. "an abstraction core must not import provider SDKs"), layered over per-component foundation status
- Full enforcement surface: eleven CLI commands, a go/analysis analyzer reporting violations at the offending import line, a composite GitHub Action, and a self-contained multi-page HTML report

### Added

- Component model with longest-prefix locator resolution and status semantics (governed, foundation, deprecated, ungoverned) ([`f78efee`](https://github.com/grokify/deppolicy/commit/f78efee))
- Dependency graph document types with evidence provenance (source-import, manifest), scan-level metadata, edge merging, and graph-to-graph diffing ([`a73df5f`](https://github.com/grokify/deppolicy/commit/a73df5f))
- Policy document types and pure evaluator: scope patterns, reason-required relationships, expirable exceptions, tier rules with mayDependOn/mayNotDependOn, four-state findings ([`1d6c787`](https://github.com/grokify/deppolicy/commit/1d6c787))
- JSON Schemas generated from the policy and graph Go types, embedded for non-Go consumers ([`882767b`](https://github.com/grokify/deppolicy/commit/882767b))
- Go scanners: go.mod manifests, ImportsOnly source imports, bounded-concurrency multi-root scanning with a shared component registry, and GitHub-API fleet scanning with no cloning ([`1629228`](https://github.com/grokify/deppolicy/commit/1629228))
- Analytics tables (Policy/Actual/Difference as flat JSON/CSV) and a self-contained multi-page HTML report with an interactive org-grouped dependency graph ([`746cc2a`](https://github.com/grokify/deppolicy/commit/746cc2a))
- deppolicy CLI: scan, scan-github, check, diff (ratchet), policy-diff, validate, promote, report, export (Mermaid/DOT), tables, and ui ([`34e9923`](https://github.com/grokify/deppolicy/commit/34e9923))
